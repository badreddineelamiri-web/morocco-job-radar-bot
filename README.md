# Morocco Job Radar Bot 🇲🇦

نظام آلي سريع لجلب وظائف المغرب ونشرها على فيسبوك باحترافية باستخدام الذكاء الاصطناعي.

## المميزات ✨

- **جلب سريع للوظائف**: باستخدام مكتبة Scrapling السريعة
- **منع التكرار**: نظام لتتبع الوظائف المنشورة سابقاً
- **صور احترافية**: إنشاء صور مخصصة مع شعارات الشركات والنصوص العربية الواضحة
- **نشر آلي**: نشر الوظائف على فيسبوك مع رابط التقديم في أول تعليق
- **دعم الذكاء الاصطناعي**: توليد منشورات عربية احترافية باستخدام عدة مزودي AI
- **قوالب جاهزة**: نظام عمل بقالب جاهز لا يتغير (job_template.png)

## المتطلبات 📋

- Python 3.8+
- مفاتيح API للذكاء الاصطناعي (موجودة في `.env`)
- صورة القالب: `assets/job_template.png` (موجودة مسبقاً)
- حساب فيسبوك مع Page Access Token

## التثبيت 🛠️

1. استنساخ المشروع:
```bash
git clone https://github.com/yourusername/morocco-job-radar-bot.git
cd morocco-job-radar-bot
```

2. تثبيت المتطلبات:
```bash
pip install -r requirements.txt
```

3. تأكد من وجود ملف `.env` مع الإعدادات الصحيحة.

## كيفية العمل ⚙️

1. **جلب الوظائف**: يجلب الوظائف من المصادر المحددة باستخدام Scrapling
2. **تصفية الوظائف**: يتجاهل الوظائف المنشورة سابقاً
3. **توليد المنشور**: يستخدم AI لكتابة منشور عربي احترافي
4. **إنشاء الصورة**: يدمج النصوص العربية والشعارات مع القالب الجاهز
5. **النشر**: ينشر الصورة والمنشور على فيسبوك مع رابط التقديم في أول تعليق

## ملاحظات هامة ⚠️

- **لا تغير صورة القالب** `assets/job_template.png` - النظام مصمم للعمل معها
- تأكد من توفر مفاتيح API في ملف `.env`
- في وضع DRY_RUN، يتم تجربة النظام دون نشر فعلي
- النظام يدعم عدة مزودي AI ويتحول تلقائياً بينهم
